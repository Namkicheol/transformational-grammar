## 📌 이 글의 활용 방법

위 퀴즈 앱은 **Radford의 『Transformational Grammar』(국제판) Ch.3 Phrase-markers**에서 다루는 세 핵심 개념 — **C-command, Anaphors, NPI *ever*** — 을 정비문 판별 방식으로 점검할 수 있는 **30문제 OX 퀴즈**입니다.

각 문항은 문법적(정문) 또는 비문법적(비문)으로 판정해야 하며, 단순 직관이 아니라 **구조적 근거(c-command, 결속 조건, NPI 인가)** 로 판단 기준을 훈련하는 것이 목표입니다.

## 🧠 "정비문 판별"이 Ch.3에서 특히 중요한 이유

Ch.3의 핵심 훈련은 "이 문장이 왜 문법적인가/비문법적인가"를 **구조적으로 설명하는 능력**을 키우는 것입니다. Ch.2까지의 구성소 테스트와 달리, Ch.3 문제는 **같은 단어를 쓴 두 문장이 구조적 차이에 의해 문법성이 갈리는 경우**가 많습니다.

예를 들어:

```
① John said that Mary hurt himself.   ❌
② John said that Mary hurt him.       ✅ (him = John)
```

두 문장의 유일한 차이는 *himself* vs *him*입니다. 그런데 문법성이 정반대입니다. 이 차이를 **결속 영역과 c-command**로 설명할 수 있어야 Ch.3를 제대로 익힌 것입니다. 정비문 퀴즈는 바로 이 판별 능력을 반복 훈련하는 도구입니다.

## 📋 정비문 판별의 핵심 체크리스트

각 문항을 풀 때 아래 4단계를 머릿속에서 빠르게 거치세요.

### 1단계 — 문항의 쟁점 파악

문장을 보자마자 다음 중 어느 것이 핵심 쟁점인지 분류합니다.

- **Anaphor** (*himself, themselves, each other*)가 있는가 → 결속 조건 확인
- **Pronoun** (*him, her, them*)의 지시가 문제되는가 → 자유 조건 확인
- **NPI** (*ever, any, at all*)가 있는가 → 부정 c-command 확인
- **C-command 관계 자체**를 묻는가 → tree 구조 확인

### 2단계 — 선행사 또는 인가자 확인

Anaphor와 Pronoun 문제라면 **선행사(antecedent)**가 누구인지 확인합니다. NPI 문제라면 **인가자(licensor)**가 될 부정 표현을 찾습니다.

### 3단계 — C-command 관계 확인

선행사 또는 인가자가 해당 anaphor/pronoun/NPI를 c-command하는지, 그리고 결속 영역 내/외에 위치하는지 tree를 머릿속에 그려봅니다.

### 4단계 — 최종 판정과 근거 정리

O/X 판정 후, 판정 근거를 한 문장으로 정리합니다. 이 문장이 논술 답안의 뼈대가 됩니다.

> 💡 **현직쌤 팁**: 퀴즈를 풀면서 "O/X만 맞히는 것"을 목표로 삼으면 안 됩니다. 30문제를 풀었을 때 각 문항의 **정답 근거 30개**가 쌓여야 진짜 학습입니다. 이 근거 모음이 실전 논술에서 그대로 쓰이는 서술 재료가 됩니다.

## 📝 자주 나오는 함정 유형

### 함정 1. 선행사가 결속 영역 밖에 있는 anaphor

```
*John thinks that Mary likes himself.
```

*himself*의 선행사로 보이는 *John*이 내포절 밖에 있어 결속 영역이 맞지 않습니다. 표면적으로 의미가 통하는 것 같지만 비문입니다. 이 함정은 임용 기출에서 매우 자주 출제되는 패턴입니다.

### 함정 2. Pronoun이 너무 가까운 선행사를 가리키는 경우

```
*John hurt him. (him = John일 때)
```

*him*이 같은 절 안의 *John*을 가리키려 하면 결속 영역 내 결속이 되어 비문입니다. *him*과 *John*을 다른 사람으로 해석하면 정문이지만, 문제에서 동일 지시를 전제한다면 비문입니다.

### 함정 3. 부정 표현의 위치가 NPI를 c-command하지 못하는 경우

```
*Anyone didn't come.
```

*anyone*이 주어 자리에 있어 *didn't*보다 tree에서 높은 위치에 있습니다. 즉, *didn't*가 *anyone*을 c-command하지 못하므로 비문입니다. "부정문이니까 NPI가 가능하다"라는 단순 논리로는 잡아내지 못하는 함정입니다.

### 🌳 함정 3 시각화 — 왜 Anyone이 주어에 오면 안 되는가

**[여기에 이미지 삽입 → tree_05_npi.png]**

오른쪽 tree가 함정 3을 그대로 보여줍니다. *Anyone*이 S의 바로 아래 주어 위치에 있기 때문에, 더 아래에 있는 *doesn't*가 위로 c-command를 보낼 수 없습니다. 선형 순서가 아니라 **구조적 높이**가 문법성을 결정하는 것이 이 함정의 교훈입니다.

> 💡 **현직쌤 팁**: 이 세 함정 패턴은 서로 다른 개념(결속 영역, 상보 분포, c-command)을 묻지만, **모두 tree 구조로 설명된다**는 공통점이 있습니다. Ch.3 전체가 "tree 위에서 구조적 관계를 읽는 훈련"이라는 것을 이해하면 함정에 덜 걸립니다.
